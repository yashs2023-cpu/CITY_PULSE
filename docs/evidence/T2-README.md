# T2 Evidence Directory

Commit generated tool outputs here after running the T2 scripts on the final `t2-metrics` branch.

Recommended files:

- `code-metrics.json` — generated by `node scripts/t2-code-metrics.js`.
- `system-quality.json` — generated by `node scripts/t2-system-quality.js`.
- `coverage/` — generated by the repository's coverage tool, if supported.
- raw `log-summary.js` / `log-analysis.js` output captured as text when the team uses those tools.

Do not commit `.env`, API keys, passwords, tokens, or private credentials.
